# Football-Honk 🪿

**Football-Honk is my modelling and projections for Football/Soccer competitions**

### Active/Live Modelling and Projections
Latest modelling and projections can be found at [Football-Honk](https://football-honk.streamlit.app). All modelling and projections are automatically refreshed (at least) once daily.

Currently, Football-Honk provides the following modelling and projections:
* Projections for upcoming games include xG and win/draw/loss probabilities for both teams
* Season expectations, including xPts
* Monte-Carlo simulation frequencies, including title/CL/relegation/etc. probabilities

Currently, Football-Honk covers the following competitions:
* English Premier League
* Bundesliga
* Serie A
* Ligue 1

Raw models can be found at source/honk/models, and detailed projections data can be found source/honk/projections.
